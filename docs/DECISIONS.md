# Decisions and open questions

## Decided

| Decision | Detail |
| --- | --- |
| No fixed civilizations | Identity comes from play: figures attracted, traditions refined |
| Leader | 6–8 invented archetypes, fixed all game; cosmetic colors + skin tone |
| Founding dream | Pick 1 of 3; motto in an old language |
| Figure acquisition | Mix of points thresholds (pick 1 of 3), deeds/achievements, conquest |
| Figures are age-locked | One legend slot per age |
| Unique worldwide | Capture cities to take figures; eliminate rivals to take all |
| No exile | Figures can be consumed for a one-time bonus instead |
| Affinity | Hidden; hints only |
| Ages | 4 ages with crises and soft reset at transitions |
| Refinement | Point budget; heavier cultures cheaper/deeper; curated hybrids |
| Dictators | Only as negative dark events |
| Founders of living religions | Excluded entirely |
| Colonial-era traditions | Included honestly; chattel slavery is never a tradition |
| Platform | Browser PWA, iPhone, offline, ~4 h game, 3D hex |
| Art direction | Dorfromantik / Townscaper diorama; stand-in art until the game is fun |
| Turn count | A tuning goal over time, not P0 |
| Asset generation | Revisit once fun; owner has a Tripo Studio account; ElevenLabs for audio |
